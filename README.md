# Aniimo Atlas v0.2

Aniimo Atlas is a free, mobile-first, unofficial fan-made companion website.

## v0.2 changes
- Renamed the project from Aniimo Companion to **Aniimo Atlas**.
- Removed invented starter Aniimo data.
- Added an explicit verified-data workflow: game facts should be sourced and checked before publication.
- Added an optional Ko-fi support area; core features remain free.
- Added the official Aniimo site as the verification reference in the empty-data state.
- Retained the explicit non-affiliation notice and Terms & Conditions.
- Retained local collection/build storage.
- Retained PWA/mobile foundation.

## Free hosting
GitHub Pages can host a static HTML/CSS/JavaScript project from a GitHub repository. On GitHub Free, the repository must be public.

## Donations
The donation button currently points to the generic Ko-fi site. Replace the href in `index.html` with your own Ko-fi creator URL once you create the account. Ko-fi's current free option allows 0% service fee on one-time tips when the account is opted out of the 5% contributor/service-fee mode; payment processor fees can still apply.
